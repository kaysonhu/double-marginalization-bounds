==============================================================================

   -> mu' = -1 + D D''/(D')^2 :  VERIFIED

   => ALPHA-CONCAVITY  <=>  mu'(p) <= -alpha   (key inequality)
rho(c) = dp_m/dc = -Derivative(D(x), x)/((c - x)*Derivative(D(x), (x, 2)) - 2*Derivative(D(x), x))
